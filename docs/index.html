Requirements

Will It Run?

Minimum

  • CPU: 64-bit x86, dual-core
  • RAM: 4 GB
  • Disk: 20 GB
  • GPU: Vulkan 1.1
  • Boot: UEFI
Recommended

For Gaming

  • CPU: Quad-core with AVX2
  • RAM: 8 GB+
  • Disk: 50 GB+ SSD
  • GPU: AMD RX 5000+ / NVIDIA GTX 1000+
  • Boot: UEFI + Secure Boot
Download

Get ZEN-OS

Download the ISO, verify the checksum, write to USB, boot.

1. Download

Grab the latest ISO from GitHub Releases.

Download v1.0.0-alpha

2. Verify

Check the SHA256 checksum matches.

sha256sum -c live-image-amd64.hybrid.iso.sha256

3. Write

Flash to USB with dd or Ventoy.

sudo dd if=zen-os.iso of=/dev/sdX bs=4M status=progress && sync
