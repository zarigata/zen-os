── Get ZEN-OS ──

01

Download

Grab the ISO from GitHub Releases.

▼ Download v1.0.0-alpha
02

Verify

sha256sum -c live-image-amd64.hybrid.iso.sha256
03

Write

sudo dd if=zen-os.iso of=/dev/sdX bs=4M status=progress && sync

or just drop the ISO on a Ventoy drive

Build from source

git clone https://github.com/zarigata/zen-os.git
cd zen-os
make build

Docker-based. Works on any OS. 15–45 min. Full guide → BUILD.md
