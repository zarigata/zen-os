WHY ZEN-OS

Built around real desktop workflows.

Not just a theme pack. The goal is a practical workstation that can move from Steam to KiCad to Docker without rebuilding the machine around each task.

ZEN-OS TOOLS

Support tools that ship with the OS.

ZEN-OS now includes its own maintenance layer instead of relying on documentation alone.

ZEN-OS Doctor

Checks storage, services, firewall state, Vulkan, Steam/Wine, firmware and dpkg health, then can save a support report.

Update Center

Handles Debian updates, per-user Flatpak updates and supported firmware updates from one menu.

Security Center

Reviews firewall/AppArmor/update status and explicitly enables or disables SSH and KDE Connect access.

Control Center

One launcher for diagnostics, updates, security, performance profiles, software, hardware information and KDE settings.

Built ISO verification

make test-iso inspects the boot payload, squashfs, package manifest and shipped ZEN-OS tools. It is deliberately more meaningful than checking only that an ISO file exists.

CURRENT LIMITS

What ZEN-OS does not pretend is finished.

  • No current downloadable ISO asset is attached to the prerelease yet.
  • Proprietary NVIDIA drivers are not preinstalled.
  • Secure Boot is disabled in the current live-build configuration.
  • Gamescope is not currently shipped as a native package.
  • Handheld-specific power/fan tuning still needs broader physical testing.
